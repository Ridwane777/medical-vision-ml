# Medical Vision ML (demo)

Two classical machine-learning demos from [github.com/Ridwane777/medical-vision-ml](https://github.com/Ridwane777/medical-vision-ml):

1. **Knee X-ray**: probability-like score for radiographic osteoarthritis (KL >= 2) from a HOG descriptor and a
   logistic regression, with the HOG cells displayed.
2. **Cluster your texts**: upload any CSV of short texts; the column, language, number of clusters and algorithm
   are chosen automatically.

**Not a medical device.** Research and education only; trained on one public dataset. See the model card in the
repository for the exact test metrics and limitations.

Licenses: code MIT (see the repository). Example X-rays: Chen (2018), Mendeley Data, doi:10.17632/56rmx5bjcr.1,
CC BY 4.0 (see `examples/ATTRIBUTION.md`). The text sample is synthetic.
