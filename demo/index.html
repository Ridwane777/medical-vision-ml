About

  • Knee X-ray classifier: a hand-written HOG descriptor + standardization + logistic regression separates KL 0-1 from KL 2-4 (radiographic osteoarthritis). The decision threshold is set on the validation split for 85% recall, then the test split is used once. This page runs the light demo model (a JSON file of plain numbers) with a small JavaScript port of the Python predictor; the repository's tests check that both give the same score. The full study's best model (HOG + SVC) reaches test ROC-AUC 0.861 but weighs 200 MB.
  • Text clustering: TF-IDF + truncated SVD, then K-Means or HDBSCAN chosen automatically by silhouette, with automatic detection of the delimiter, header, text column and language. It runs the project's own Python code in the browser with Pyodide 314.0.7 (Python 3.14, scikit-learn 1.8.0, pandas 3.0.2): the first visit to that tab downloads the runtime (about 23 MB, 30 s to 2-3 minutes).

Source code, notebooks, model card and data cards: github.com/Ridwane777/medical-vision-ml (model card).

Example X-rays: Chen, P. (2018), Knee Osteoarthritis Severity Grading Dataset, Mendeley Data, doi:10.17632/56rmx5bjcr.1, CC BY 4.0. The text sample is synthetic (no real patient text).
